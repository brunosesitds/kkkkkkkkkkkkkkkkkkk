Módulo 5 – Sexta-feira
Programação de Aplicativos
Valor: 2,0 pontos
Tempo estimado: 3h
Objetivo
Desenvolver um aplicativo utilizando React Native com Expo.
Tema
Calculadora
Requisitos
Criar um aplicativo contendo:
Tela inicial
Capa personalizada.
Tema relacionado a cálculos ou matemática.
Navegação
O aplicativo deverá possuir 4 abas (Tabs):
Soma
Subtração
Multiplicação
Divisão
Cada aba deverá conter:
Dois campos numéricos.
Botão para calcular.
Exibição do resultado.
Requisitos técnicos
React Native.
Expo.
Utilizar uma versão estável do Expo (não necessariamente a mais recente).
O aluno deverá iniciar um projeto novo e deixá-lo funcionando corretamente antes do desenvolvimento.
Inteligência Artificial
É permitido utilizar ferramentas como:
ChatGPT;
Claude;
Gemini;
para auxiliar no desenvolvimento (Vibe Coding). Entretanto, o aluno deverá compreender o funcionamento do código produzido e ser capaz de explicar sua implementação.
Criatividade
A identidade visual do aplicativo é livre.
Nome do repositório
APP-REC
